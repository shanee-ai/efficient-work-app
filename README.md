# WorkAI — AI-Powered Workplace Assistant

WorkAI is an internal MVP that helps knowledge workers save time on repetitive workplace tasks. It uses a secure AI gateway to generate emails, summarise meeting notes, and plan the working day from a task list.

Built with [TanStack Start](https://tanstack.com/start), React 19, TypeScript, and Tailwind CSS v4.

---

## Features

### 1. Smart Email Generator
- Write professional emails from a few inputs: purpose, recipient, key points, tone, and length.
- Generated drafts include a subject line, greeting, body, and closing.
- One-click actions: copy, regenerate, make shorter, make more professional.

### 2. Meeting Notes Summarizer
- Paste raw meeting notes and add a title + participant list.
- AI returns a structured summary: key points, decisions, action items with owners and deadlines, and follow-ups.

### 3. AI Task Planner
- Manage a personal task list with name, description, deadline, priority, and estimated duration.
- AI analyses the task list and returns:
  - The top priority for the day
  - A recommended schedule with realistic time slots
  - Concise planning advice

### 4. Dashboard
- Professional landing page with a greeting, feature cards, and live usage statistics.
- Stats and tasks are stored in `localStorage` so the demo state persists across reloads.

### 5. Responsible AI
- A visible disclaimer reminds users that AI outputs may contain errors and should be reviewed before use.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (latest LTS recommended)
- [Bun](https://bun.sh/) or npm

### Install

```bash
bun install
# or
npm install
```

### Run Development Server

```bash
bun run dev
# or
npm run dev
```

The app will be available at `http://localhost:8080`.

### Environment Variables

The app expects the AI gateway API key to be available at runtime. In local development this is usually supplied by the Lovable environment.

```bash
LOVABLE_API_KEY=your_key_here
```

## How It Works

- **Frontend routes** live in `src/routes` and are rendered by TanStack Router.
- **Server functions** in `src/lib/workai.functions.ts` receive validated input, call the AI gateway, and return structured output.
- **Browser state** for tasks and stats is kept in `localStorage` via `src/lib/workai-store.ts` so the demo is self-contained.
- **Design tokens** are defined in `src/styles.css` using Tailwind v4 CSS-first configuration.

## Responsible AI Statement

AI-generated content is a starting point, not a final fact. Always review generated emails, summaries, and task plans before sharing or acting on them. Do not paste confidential or regulated information unless your organisation allows it.
